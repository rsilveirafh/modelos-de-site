# Modelos de site pessoal

Dois modelos de site pessoal, sem conteúdo, só para mostrar a estrutura.

- **Essencial** (`essencial/`): uma página com apresentação, sobre, o que faço, trabalhos selecionados e contato. Em português.
- **Completo** (`completo/`): cinco seções (Início, Sobre, Portfólio, Galeria e Contato), em português e inglês, com filtro no portfólio, galeria de fotos e formulário de contato.

As seções mudam conforme a pessoa: Pesquisa, Publicações e Campo para quem pesquisa; Serviços, Depoimentos e Blog para quem atende clientes.

É HTML, CSS e um pouco de JavaScript, sem etapa de build, publicado pelo GitHub Pages.
Para ver localmente, abra `index.html` no navegador.
